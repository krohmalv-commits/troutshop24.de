# Чеклист миграции с Ecwid на WordPress

## 1) Контент и структура
- [ ] Собрать список всех URL старого сайта.
- [ ] Определить обязательные страницы: Home / Shop / About / Contact / FAQ / Shipping / Returns.
- [ ] Заполнить `content-inventory.csv`.
- [ ] Скопировать тексты, заголовки, meta title/description.
- [ ] Подготовить изображения (hero, категории, товары, логотип, favicon).

## 2) WordPress базовая настройка
- [ ] Включить ЧПУ: `/%postname%/`.
- [ ] Создать меню (Header/Footer).
- [ ] Настроить логотип, favicon, соцссылки.
- [ ] Создать статическую главную страницу.

## 3) Магазин (WooCommerce)
- [ ] Валюта, налоги, доставка.
- [ ] Импорт товаров (CSV) или ручное добавление.
- [ ] Категории/атрибуты/вариации.
- [ ] Способы оплаты.
- [ ] Тестовый заказ.

## 4) SEO и редиректы
- [ ] Для старых URL настроить 301 редиректы.
- [ ] Перенести meta title/description на ключевые страницы.
- [ ] Проверить robots.txt и sitemap.xml.
- [ ] Подключить Google Search Console и GA4.

## 5) Качество и запуск
- [ ] Проверить мобильную версию и скорость.
- [ ] Проверить формы, корзину, оплату, email-уведомления.
- [ ] Сделать бэкап перед запуском.
- [ ] Опубликовать сайт и прогнать финальный smoke test.
