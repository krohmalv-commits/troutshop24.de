# Assets for 1:1 visual clone

Use this folder to keep the original front-end assets from badsquiddogames.com.

## Expected files
- `css/site.css` — main original stylesheet
- `js/site.js` — original behavior scripts (optional)
- `img/*` — images, icons, logos, backgrounds

`functions.php` auto-loads `assets/css/site.css` and `assets/js/site.js` if they exist.
