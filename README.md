# Восстановление сайта troutshop24.de на WordPress (1:1 без редизайна)

Вы правы: для 1:1 копии нужен перенос оригинальных ассетов, а не новый дизайн.

## Что внутри
- `wp-theme/hallo-troutshop/` — тема-оболочка WordPress для точного переноса внешнего вида.
- `wp-theme/hallo-troutshop/assets/` — папка для оригинальных CSS/JS/IMG.
- `migration-checklist.md` — чеклист миграции.
- `content-inventory.csv` — таблица инвентаризации контента/URL/SEO.

## Структура ассетов (обязательно)
- `wp-theme/hallo-troutshop/assets/css/site.css`
- `wp-theme/hallo-troutshop/assets/js/site.js` (опционально)
- `wp-theme/hallo-troutshop/assets/img/...`

Тема автоматически подключит `assets/css/site.css` и `assets/js/site.js`, если файлы существуют.

## Как сделать 1:1
1. Активируйте тему `Hallo Troutshop`.
2. Создайте страницу `Home` и назначьте ее главной.
3. Вставьте в контент страницы Home HTML-разметку, максимально близкую к старому сайту.
4. Скопируйте оригинальные CSS/JS/изображения в `assets/`.
5. Проверьте визуальное совпадение (шрифты, отступы, кнопки, фон, карточки, хедер/футер).
6. Настройте WooCommerce и вставьте его шорткоды/блоки в нужные места той же разметки.

## Важно
Без доступа к исходным файлам старого сайта невозможно автоматически гарантировать «1 в 1».
Но с этой темой вы можете перенести оригинальные ассеты без изменения дизайна со стороны темы.
